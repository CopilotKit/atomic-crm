# Documentación de Atomic CRM

Este paquete contiene el sitio de documentación de Atomic CRM. Forma parte del espacio de trabajo pnpm de la raíz, así que instala las dependencias desde la raíz del repositorio:

```sh
pnpm install
```

Ejecuta el sitio de documentación desde la raíz del repositorio:

```sh
pnpm --filter atomic-crm-doc run dev
pnpm --filter atomic-crm-doc run build
pnpm --filter atomic-crm-doc run preview
```
