# Atomic CRM documentation

This package contains the Atomic CRM documentation site. It is part of the root pnpm workspace, so install dependencies from the repository root:

```sh
pnpm install
```

Run the documentation site from the repository root:

```sh
pnpm --filter atomic-crm-doc run dev
pnpm --filter atomic-crm-doc run build
pnpm --filter atomic-crm-doc run preview
```
