# Documentation d’Atomic CRM

Ce package contient le site de documentation d’Atomic CRM. Il fait partie de l’espace de travail pnpm à la racine ; installez donc les dépendances depuis la racine du dépôt :

```sh
pnpm install
```

Lancez le site de documentation depuis la racine du dépôt :

```sh
pnpm --filter atomic-crm-doc run dev
pnpm --filter atomic-crm-doc run build
pnpm --filter atomic-crm-doc run preview
```
